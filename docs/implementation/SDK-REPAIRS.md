# SDK 缺陷修复记录

日期：2026-11-01。范围为本轮 SDK 审查确认的六项缺陷，依据为 SDK 接入文档与 [链路规格](../design/TRACES-SPEC.md)。

## 目标与实施方案

| 缺陷                     | 目标行为与修复位置                                                                                                  | 验证入口                                               |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| 持续入队推迟自动导出     | tracing exporter 保留已安排的最早发送截止；flush 可提前调度，发送仍遵守既有 Retry-After                             | tracing 单测，持续输入且不主动 flush                   |
| 异常 429 响应体丢失退避  | event transport 独立处理 429 和 Retry-After；不使用未经验证的错误项删除事件，合法响应中的 retry_after_ms 仍参与等待 | SDK 单测，文本、错误结构和错误索引响应                 |
| resource 漏算系统属性    | 初始化将两个系统属性纳入数量、节点和字节预算，超限配置立即拒绝                                                      | tracing 单测，126/127/128 属性及配置预算边界，协议解码 |
| 非有限 double 变为空值   | tracing 快照将数值 NaN/Infinity/-Infinity 规范化为对应字符串，保留合法有限数值                                      | tracing 单测，经实际协议解码检查值                     |
| 非法 tracestate 中断传播 | 只删除非法 tracestate，合法 trace/span ID 继续传播和继承；配置规则仍独立校验                                        | tracing 单测，inject、parent/link 和非法 ID            |
| 关闭后 ALS 残留          | close 不等待业务回调；存量回调保留上下文，在最后一个 withSpan 回调退出后释放 ALS；关闭后的 withSpan 同样有完整清理  | tracing 单测与发布产物的真实 Node GC 回归              |

429 的修复同时覆盖响应体停滞后的请求超时，以及超长 Retry-After 的平台定时器溢出：transport 将已收到的限流结果交给 core 的取消路径，定时器分段等待并保留真实冷却截止。HA 探针作为内部调用方同步接入限流通知，收到 429 即取消响应读取并停止端点轮换。对应测试包含停滞流与真实 Node 警告观测。

公共导出、HTTP/DTO、数据库、凭证、前端入口和配置字段不变。初始化收紧不合法 resource 预算；没有持久化迁移、兼容窗口或双轨实现。event ACK 与 trace partial success 的独立语义保持不变。

按回归失败证据、最小实现、定向验证、独立只读审查、完整四项检查的顺序完成。验收命令使用现有 lint、typecheck、build、test；完整 test 包含 Vitest 集成覆盖率和开发/生产浏览器冒烟。

## 验证证据

修复前，SDK 回归有 12 项因原缺陷失败；真实 Node 发布产物 GC 回归发现 100 个关闭后的 ALS 实例仍存活。独立审查补充的停滞响应体和超长 Retry-After 两项回归也分别取得修复前失败证据。修复后上述用例全部通过。

独立只读审查覆盖初版全部差异，确认的两项 429 边界均已修复；定向复核再执行慢响应、同端点同载荷重试、主动关闭取消、HA 通知后取消、合法响应体较长等待和超长定时器六个 Node 场景，未发现剩余问题。
